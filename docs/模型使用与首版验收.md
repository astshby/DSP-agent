# v1.0 模型使用与首版验收

第 5—15 周共 11 次的工程版本已提供。第十四周接 OpenAI，第十五周增加 DeepSeek。两家官方 API 适配与本地完整流程已实现，自动验证使用模拟供应商响应，**真实账号调用仍需在你的电脑完成**。任务书要求至少一种模型实际跑通，不能以模拟测试代替这一项。

## 1. 两种打开方式

| 使用方式 | 打开入口 | 能做什么 |
|---|---|---|
| 离线 | 双击 `self/第十五周/index.html` | 全部 DSP、手动/CSV、规则助手、任务和报告导出；不需要 Node 或 Key |
| 第十四周模型实验 | 根目录 `npm start` 后打开 `http://127.0.0.1:8787/?week=14` | 离线能力 + OpenAI 模型面板 |
| 第十五周模型实验 | 根目录 `npm start` 后打开 `http://127.0.0.1:8787/` | 离线能力 + OpenAI / DeepSeek 切换 |

后两项需要 Node.js 20+，没有第三方 npm 依赖，无需 npm install。Windows 可双击 `start-local.cmd`；macOS/Linux 执行 `./start-local.sh`，再打开终端地址。结束时 Ctrl+C。完整模型交付包含根目录页面、src、server、package.json 和启动脚本，不能只交一个 HTML 并期待它自行启动后端。

## 2. 配置自己的账号

1. 在官方开发者平台创建 API Key，确认账号可用模型与 API 余额。ChatGPT Plus/Pro 不包含 OpenAI API 额度。
2. 在页面中间栏下方找到“云端模型助手”，选择服务商，展开“模型设置与连接测试”。
3. 填模型 ID 和 Key，点击保存。默认示例：OpenAI `gpt-4.1-mini`、DeepSeek `deepseek-chat`。可以修改为你账号实际可用、支持 function tools 的模型。默认值未经过本次实时账号验证。
4. Key 输入框保存后清空；重开页面只显示“已保存”。只改模型 ID 时，Key 留空会保留原值。点删除配置可移除这一家的本地 Key 和模型设置。
5. 点“测试模型与工具”。后端会让模型对固定测试序列 `[1,2,1]` 调用本地分析工具，再返回说明；应显示“连接与工具调用通过”。仅文字回复而不调用分析工具会被判为测试未通过。

测试会产生真实 API 请求，可能收费；保存配置和纯离线操作不调用模型。没有真实 Key 时，仍可点左侧“保存、复现与本地服务 → 本地工具自检”，它完全使用模拟助手，不收费。

## 3. Key 保存位置与发送内容

默认：当前用户目录下 `.dsp-agent/providers.json`，例如 macOS/Linux 的 `~/.dsp-agent/providers.json`、Windows 的 `%USERPROFILE%\.dsp-agent\providers.json`。文件包含各服务商 model/apiKey，为明文。Unix 文件权限 600，新建目录 700；Windows 继承用户目录权限。首版未集成系统加密凭据库。

可在启动前设置 `DSP_CONFIG_DIR`，选择项目之外的私人配置目录。配置不在仓库、浏览器 localStorage、导出报告或任务 JSON 中；不要手动把它复制进 GitHub。网页仅临时持有输入的 Key，后端查询设置不会回传它。

后端只向固定官方地址发送对应 Key：

- OpenAI：`https://api.openai.com/v1/chat/completions`
- DeepSeek：`https://api.deepseek.com/chat/completions`

模型收到用户文字、信号 ID、采样率、长度、统计量、当前操作参数及本地工具结果摘要。原始输入数组/CSV 不自动发送；你主动写进文字的内容、卷积核与系统系数仍会成为请求内容。浏览器和本地后端之间传输完整信号用于计算与绘图。

## 4. 推荐的首个真实实验

1. 点击“恢复默认正弦实验”：fs=1000 Hz、64 项。选已通过测试的模型服务。
2. 输入：`对当前信号做二阶 Butterworth IIR 低通，截止100Hz，再用256点Hann窗FFT看频谱。请解释结果。`
3. 点击“发送给模型并预览”。后端发起推理，模型返回工具名与参数，本地校验/执行并把摘要交给模型。页面先显示说明、工具轨迹、步骤和指标，原图保持原样。
4. 核对实际步骤包含 IIR、lowpass、100 Hz 和 FFT、256、Hann。模型的解释可能有误，应以显示的参数和本地计算为准。
5. 点击“应用计算结果”。图表更新，左侧设置同步。再输入 `截止改为150Hz，保留其余处理`，检查仍只有两个步骤，应用后频谱重算。
6. 下载“模型记录”，包含服务商、模型 ID、用户要求、模型说明、调用轨迹、任务和指标，不包含 Key。再导出任务 JSON、输出 CSV 和实验报告；补充自己的实验观察和截图。

模型只负责当前信号的处理分析；要换成双频、噪声或导入文件，先在左侧完成。它可请求澄清或返回文字，不一定每次都有可应用结果。下一次请求基于当前任务，不保留完整聊天历史；追问时应写全仍缺少的条件。

## 5. 双模型对照与边界检查

- 分别恢复同一默认信号，给 OpenAI 和 DeepSeek 同一条明确的请求，保存两份模型记录。比较最终任务和工具计算；相同规范化任务应有一致数值，解释文字可以不同。若任务参数不同，先统一参数，不能直接把结果差异解释成算法错误。
- 未应用时改样本数/采样率，旧预览应不可执行；请求期间修改实验，返回结果会被丢弃。
- 请求运行时点击取消，应回到可发送状态，实验图保持原样。已产生的云端 token 仍可能计费。
- 让模型做不支持的带通或错误截止频率，应说明限制/修正；工具契约不会允许无效计算。模型自然语言行为不保证每次相同。
- 删除某家配置，再发送，应提示先保存 Key；另一家的配置应保留。
- 断网打开周目录 HTML，模型按钮禁用，手动与规则实验仍能运行。

## 6. 常见错误

| 提示 | 检查项 |
|---|---|
| 未找到兼容本地服务 | 启动 v1.0 根目录的 npm start；不要用其他静态服务器代替 |
| 401 | Key 是否属于该服务商、是否有效；两家 Key 不能混用 |
| 403 | 账号、地区或组织权限；以官方控制台为准 |
| 404 | 模型 ID 是否存在、账号是否有权限；修改后保存再测试 |
| 429 | API 余额、限额或请求频率；不要把聊天订阅当作 API 余额 |
| 连接失败 / 超时 | 电脑能否连接对应官方 API；检查网络代理设置，普通 Node fetch 不保证自动继承浏览器代理 |
| 模型参数不是合法 JSON / 输出截断 | 缩短请求，或更换支持工具调用的模型；模型原始文本不会作为代码执行 |
| 未成功调用分析工具 | 模型只回答了文字，或连续参数错误；尝试明确要求调用工具，或换模型 |
| FFT 点数 / 截止报错 | 点数须不小于处理后长度，FFT 为2的幂；截止须在(0, fs/2) |

不自动重试收费请求。每次最多 6 轮、8 次工具调用、90 秒，同时最多两个云请求；本机工具计算受4096样值与8步骤限制。工具错误可以在余下轮数内由模型修正，超限终止。

## 7. 首版已实现与后续项

已实现：11 个周版本、离线规则子集、确定性 DSP、任务复现、报告与CSV导出、本地工具、两个官方 API 适配、密钥配置、错误反馈、取消/超时、预览/应用和模型记录导出。

后续项：逐字流式、长期会话、费用统计、系统凭据库、模型主动生成新信号、更多滤波类型和实时采集。首版以整次 JSON 返回结果，没有 SSE；无需安装 CC Switch 或通用 Agent 框架。

云环境完成模拟协议与界面测试，未验证真实 API 鉴权、账号可用模型、计费或具体模型的自然语言表现。实际双击 HTML 也需在你的电脑确认：云浏览器禁止 file://，本次以断网加载单文件内容验证离线能力。

# v1.0 模型接入工程方案

已实现：HTML/JavaScript 前端、Node.js 本地后端、共享 DSP、本地配置和两个官方 API 适配。具体启动和验收见 [模型使用与首版验收](模型使用与首版验收.md)。课程第十四周开放 OpenAI，第十五周开放 OpenAI / DeepSeek；前十三周的离线单文件保留。

## 工程结构

```text
浏览器：生成/导入信号 → 输入实验要求
  ↓ 本机同源 HTTP
Node 后端：配置读取 → 官方 API 适配 → 受限 Runner
                         ↓ 工具名与 JSON 参数
                 契约校验 → 共享 DSP → 结果摘要
                         ↓ 模型解释
浏览器：本地复算 → 参数/指标预览 → 用户应用 → 更新图表
```

首版使用原生 Node fetch 和项目自己的小型 Runner。先前规划的 Agents SDK 作为工程参考保留，没有引入其依赖；只有两个注册工具，无需通用代理框架。OpenAI 与 DeepSeek 都走 Chat Completions function tools，固定官方 URL，不需要 CC Switch 作为运行依赖。两家切换只影响推理，DSP 核心相同。

## 配置和通信

- `server/providers.cjs`：服务商定义、原子配置写入、脱敏读取、官方协议转换及错误映射。
- `server/runner.cjs`：多轮工具消息、错误修正、轮数/调用数/时间限制、取消。
- `server/contracts.cjs` / `tools.cjs`：只允许 DSP 操作的 schema 与本机信号/结果缓存。
- `src/cloud.js`：配置、模型请求、结果预览与应用、旧结果作废、模型记录导出。
- 默认配置文件 `~/.dsp-agent/providers.json`，单文件原子更新，包含各家 model/apiKey。Unix 文件权限 600；Windows 继承用户目录 ACL。明文存储，不是系统凭据保险箱。
- Key 查询时不返回，不进入 localStorage、实验任务或日志。模型请求只在用户点击测试/发送后发生。
- 仅监听 127.0.0.1，检查 Host/Origin、同源 JSON，静态资源白名单，不开放跨域。

## 首版范围

输入/上传在本地页面完成，模型负责当前信号的处理与分析。每次以当前任务建立上下文，不保存聊天历史。API Key、模型 ID 分服务商保存；默认模型可修改。整次返回结果与工具轨迹，尚无 SSE、逐字流式、token/金额统计、任意代理地址、后台任务恢复。取消会传到供应商请求，不能保证取消已产生的计费。

6 轮 / 8 次工具调用 / 90 秒 / 最多两个并行云任务。参数错误返回模型修正；未知工具和跨信号访问拒绝。模型文本以纯文本显示。浏览器复算成功后，用户选择应用；手动与离线规则入口始终可用。

## 验证边界

已验证官方协议形状的模拟响应、本地 HTTP 到工具执行、浏览器配置与完整交互。未携带真实凭据调用两家官方服务，未实时核对模型列表/价格。课程要求至少一种模型实际跑通，需用户本机补齐并保存模型记录。不能把模拟测试等同于实际服务兼容或计费验收。

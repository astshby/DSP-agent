# 每周离线助手：第 5—13 周按课程能力开放

v0.9.2 已为第 5—12 周补入离线规则助手。每周保留当时的 DSP 实现，使用与第十三周相同的解析、参数预览和执行方式，只开放本周能力清单中的操作。累计支持此前各周功能。

下载完整仓库或单个周目录的 `index.html`，断网双击打开即可，不需要后端、模型或 API Key。每页右侧都有本周范围和可点击示例；手机上助手在结果摘要后面。

| 课程周次 | 当周新增的助手能力 | 示例 |
|---|---|---|
| 第 5 周 | 信号生成、手动序列、采样参数、波形与统计 | `请生成100Hz正弦信号，采样率1000Hz，样本数64`；`输入序列[1,2,1]，首项下标-1`；`查看能量和RMS` |
| 第 6 周 | 增益、移位、反折 | `请把当前序列放大2倍，然后移位-3`；`反折` |
| 第 7 周 | 线性卷积，读取页面 h 或直接给出 h | `请计算卷积[1,2,1]，首项下标-1`；`按页面设置做卷积`；`卷积改成[1,0,-1]` |
| 第 8 周 | 差分方程、输入/输出历史、尾部补零 | `差分方程 b=[1]，a=[1,-0.5]，输出历史[2]`；`根据页面设置做差分方程` |
| 第 9 周 | DTFT、系统频率响应 | `请分析当前序列DTFT`；`查看系统频率响应 b=[0.5,0.5]，a=[1]` |

## 如何执行和修改

1. 在本周助手中输入要求，或点击示例按钮。
2. 点击“解析并预览”。此时实验图和指标仍保持原值；预览说明要修改输入、新增步骤、替换哪个步骤或读取指标，并标出参数来源。
3. 核对后执行。页面用本周 DSP 程序更新波形和读数，执行的系数/参数会同步到对应设置框。
4. 可以继续说“卷积改成[…]”“差分方程改成 b=[…]，a=[…]”“截止改成150Hz”“频谱改成128点DFT”等。修改针对当前任务中最近的同类型步骤，后续步骤重新计算；没有该步骤时会提示先新增。

新建操作：文字参数优先，未说明的读取页面设置。修改操作：文字参数优先，其余先沿用被修改的步骤，再读取页面设置。改变表单或要求后，旧预览会失效。若一次多步要求的后半句不支持，整个计划拒绝，不先执行前半句。

例如第六周输入“放大2倍然后FFT”，会明确提示 FFT 尚未开放，原序列和已有处理步骤保持原样。第九周已能做 DTFT，但 DFT/FFT 要到第十一周，表达时请区分。

## 输入与文件边界

- CSV 仍使用浏览器文件选择器。第六周及以后导入 CSV 后，助手使用页面当前信号；文字不会读取任意磁盘路径。
- JSON 导入导出、报告保存及本地工具流程仍由第十三周的对应按钮完成，未向历史版本回填这些后续功能。
- 频率带 Hz/kHz，辐角与相位带度/°，下标与移位为整数。生成器可修改幅值、偏置、发生位置；第十二周新增波形同样受该周清单限制。
- 历史版本仍保留该周的数值/长度约束。FFT 点数不能小于当前处理后信号长度；修改输入或卷积长度后，如不满足约束会要求修改点数。
- 有限规则支持常用表达；未知内容、相互冲突的参数、否定/条件或超出本周能力的要求会要求补充。没有把关键词出现一次就当成完整理解。

## 维护与验证

`src/capabilities.js` 定义每周累计清单、波形和示例；`src/assistant.js` 是共用解析与预览逻辑；`src/weekly-assistant.js` 把历史页面的原实验入口连接到助手。

```bash
npm run build:weekly
npm run build:offline
npm test
python tests/deliveries_browser.py
```

`build:weekly` 只为第 5—12 周重建助手增强区和周报补充，保持各周 DSP 核心代码不变，可以重复执行。`build:offline` 重建当前第十三周页面。自动测试直接运行各历史页面内的 DSP 验证示例，并验证未来能力拒绝；浏览器检查在断网模式下逐周执行示例、检查预览与窄屏操作。

云浏览器的 file:// 限制与本机双击验证方式见 `本地验证指南.md` 和 `验证记录.md`。

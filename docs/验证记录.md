# v0.9.2 验证记录

## 已完成验证

| 项目 | 实际检查与结果 |
|---|---|
| Node 单元与集成 | `npm test`：24 项通过；发生器、CSV、变换、卷积、差分、DTFT、z、DFT/FFT、滤波、规则、工具 Runner、HTTP |

| 历史交付 | `tests/deliveries_browser.py`：第 2—9 次各自单文件，无外网请求、无页面异常；验证每阶段新增操作、CSV 和窄屏布局；第九次另查规则预览与任务导入导出 |

浏览器与 Node 的数学函数存在正常舍入差异。实测默认正弦及滤波输出跨运行时最大差约 1.11e-16；自检使用每项 `|a−b| ≤ 1e−10·max(1,|a|,|b|)`，同时核对结构、长度和全部结果。主值相位按模 2π 比较，不把 +π/−π 分支差视为物理误差；明显数值错误、结构不符和非有限数值仍拒绝。

## 浏览器环境限制

本次云环境的 Chromium 对 `file://` 返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。没有绕过浏览器策略：源码用本机 HTTP 加载，独立交付用浏览器断网模式载入内嵌 HTML 内容。证明了单文件没有外部资源依赖、断网交互可执行，但**不能声称用户电脑的双击路径已测试通过**。请按本地验证指南在你的浏览器双击确认。

桌面与手机截图生成在忽略提交的 `test-results/`；截图用于检查排版，数值结论以测试与可复现任务为准。

# v0.9.1 本地验证指南

建议先验证最新第十三周，再按周报逐个打开历史页面。不要一次改很多参数；每次确认一个现象。

## 1. 无安装、断网运行

下载并解压仓库。断网，双击 `self/第十三周/index.html`。应显示 64 个默认正弦样值，无下载依赖或登录提示。手机可以使用支持打开本地 HTML 的浏览器；部分系统文件预览器不运行 JavaScript，应选“在浏览器打开”。

## 2. 基础数值与错误提示

- 正弦设 fs=8、N=8、f=1、A=1、φ=0、D=0：样值 n=0/2/4/6 约为 0/1/0/−1，能量 4。
- “输入一个序列”默认 [1,2,1]、n₀=-1、无 fs：能量 6，时间轴不可用。
- 改成 `1,,2`：报错，图保留上次有效结果。修改参数但未运行时也有提示。
- CSV 示例 `examples/sampling.csv`：数值列 2、时间列 1、首行表头，得到 1000 Hz 和 8 项。时间单位固定秒，时间原点平移到零会提示。若不选择时间列，采样率沿用表单中明确填写的值，需自行核对；可以留空。

## 3. 第二章

按 [第二章实验验收](第二章实验验收.md) 逐节操作。建议先看卷积，再看差分初值，最后看 DTFT 与 ROC。

差分方程系数 `b=[1], a=[1,-0.5]` 表示 `y[n]=0.5y[n−1]+x[n]`。历史值从最近的一项开始填。所有按钮会追加操作，重复点击意味着串联两次；比较独立实验前先清空处理。

## 4. 双频低通

展开滤波设计，点击“载入双频低通实验”。原始信号 50 Hz + 300 Hz；绿色为输出，橙色虚线为输入。FIR 通带延迟 25 项，300 Hz 峰值明显下降。不要把延迟后的输出直接与原始输入逐点相减来评价质量。

清空步骤，选择二阶 IIR、低通 100 Hz，再点击设计。IIR 群延迟随频率变化。FIR 抽头数和设计窗只对 FIR 有效。

## 5. 规则助手与复现

先恢复默认，再输入 `请用 31 抽头 Hamming 做 0.2 kHz 低通，再看频谱`。点“解析并预览”后应显示两个操作和各参数来源；此时原图不变。点执行后出现滤波与频谱结果，左侧参数同步更新。

继续输入 `截止改成 150Hz`：预览显示“修改第 1 步”，而不是新增第二个滤波器。执行后抽头数和窗函数保持该步骤原来的值，后面的频谱重新计算。再输入 `换成二阶 IIR`：仍修改同一个滤波步骤，保留 150 Hz 截止和低通类型。

其他例子：`用 30 阶 FIR、汉明窗做 200Hz 低通`（30 阶 = 31 抽头）；`查看 512 点 FFT，汉宁窗`；`频谱改成 256 点 DFT，矩形窗`。FIR 抽头数仍须为 3—129 的奇数，IIR 当前固定二阶。

新建操作时，未指定参数沿用页面设置；修改操作时，未指定参数先沿用该步骤。若单独调用规则模块、没有页面参数，截止频率缺失会要求补充；频谱点数则可按信号长度自动确定。网页中手工选好的 FFT/DFT 点数仍须满足长度和算法约束。

输入“帮我优化一下”、否定/条件要求、冲突频率、未知操作或缺少单位的数值，应要求补充，并禁用执行。修改页面参数后，旧预览失效，需要重新解析。该助手使用有限规则，不能保证理解任意句子。

下载任务 JSON，改为另一个实验，再从“恢复任务 JSON”选择刚才的文件，点击“导入并复现”。原数据、采样信息、操作与结果应恢复。CSV 数据已嵌在 JSON 中，不需要重新选择原 CSV。格式不合法、超大文件或不支持的任务会报错。

也可以直接导入 `examples/` 下的 JSON 实验。下载输出 CSV，第一列是 n，设置 fs 时第二列是秒、第三列是幅度。重新当 CSV 导入时请选择正确列，不能默认第一列就是幅度。CSV 导入会重新定义起始下标；需要精确恢复下标请用任务 JSON。

报告导出包含计算指标、解释文字和完整任务 JSON，可作为周报实验材料，但还需补上自己的观察结论。当前不导出 PNG；需要图像可自行截图。

## 6. 本地工具流程

安装 Node.js 20 或更新版本。在仓库目录运行 `npm start`，打开终端打印的地址，展开保存面板点击“本地工具自检”。预期显示两次工具调用，且结果与页面一致。双击 HTML 模式点击该按钮，会提示先启动本地服务。

这是模拟模型的工程验证。没有 API Key 输入框，不会询问密钥，不发生真实云端请求。

常见问题：

| 现象 | 处理 |
|---|---|
| `node` / `npm` 找不到 | 安装 Node.js 后重新开终端；离线页面不受影响 |
| 8787 端口占用 | 关闭旧服务，或设置 `DSP_PORT=8788` 后启动并使用新的地址 |
| Windows 设置端口 | PowerShell：`$env:DSP_PORT='8788'; npm start` |
| macOS/Linux 设置端口 | `DSP_PORT=8788 npm start` |
| FFT 点数报错 | 必须为 2 的幂，且不小于当前处理后长度；卷积会增加长度 |
| 滤波器 fs 错误 | 先补充采样率；截止频率须严格在 0 与 fs/2 之间 |
| 本地结果不存在 | 内存最多保留最近 32 个信号/结果；重启后清空，重新自检即可 |
| CSV 不等间隔 | 修改源数据；本版不自动插值重采样 |

无需端口转发或外网部署。本地后端只监听 127.0.0.1；关闭终端后离线单文件仍可运行。

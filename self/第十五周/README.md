## 运行

- 离线：双击同目录 index.html，无依赖、无需Key；可生成/导入信号、规则控制、导出并复现实验。
- 模型：完整仓库根目录运行 `npm start`，打开 `http://127.0.0.1:8787/`，在云端模型助手配置OpenAI或DeepSeek。需要Node.js20+及对应官方API账号，无需npm install。
- DeepSeek默认模型示例为deepseek-chat，OpenAI为gpt-4.1-mini；可按账号实际权限修改。保存后先测试模型与工具，再发送实验请求。

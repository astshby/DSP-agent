## 离线助手补充（v0.9.2 回填）

本页现在包含第十三周规则助手的本周子集，仍调用本周原有 DSP 程序。断网双击即可使用；不需要服务器、模型或 API Key。

本周累计能力：信号生成 / 手动序列 / 采样参数；波形与统计读数；缩放 / 移位 / 反折；线性卷积；差分方程与初始历史；有限序列 DTFT；系统频率响应；零极点 / 因果 ROC；典型逆 z 变换；有限序列 z 求值；DFT / FFT 频谱；FIR / 二阶 IIR 滤波。

可直接点击页面上的示例，也可以输入：

- `请用 31 抽头 Hamming 做 0.2kHz 低通，再看频谱`
- `截止改成 150Hz`
- `换成二阶 IIR`

先点“解析并预览”，检查参数来源，再执行。参数会同步到原表单；修改要求或表单后，旧预览失效。缺少参数时可补充文字或先填写本周设置；CSV 仍由浏览器文件选择器导入，再对当前信号发出要求。

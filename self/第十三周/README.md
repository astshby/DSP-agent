## 本地推荐顺序

1. 断网双击本页，确认默认信号可用。
2. 试双频滤波，观察频谱、FIR 延迟和输出瞬态。
3. 清空处理后试规则助手，未知表达应要求补充。
4. 导出并导入任务 JSON，确认数据与参数恢复；导出 CSV 和实验报告。
5. 需要检查未来模型接口时，启动根目录的本地后端，再进行工具自检。

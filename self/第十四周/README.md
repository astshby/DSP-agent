# 第 10 次提交 / 第 14 周 · v1.0 集成版

本周新增 OpenAI 官方 API 接入：本地模型设置、API Key 持久化、function tool calls、受限多轮执行、错误修正、取消与超时、计算结果预览和应用、模型记录导出。

## 运行

- 离线：双击同目录 index.html，全部第十三周 DSP 和规则助手继续可用；模型按钮提示启动后端。
- 模型：下载完整仓库，安装 Node.js 20+，根目录运行 `npm start`，打开 `http://127.0.0.1:8787/?week=14`。该页面只显示 OpenAI。
- 保存自己的 OpenAI API Key 和可用模型 ID，再点“测试模型与工具”。密钥保存在用户目录 `.dsp-agent/providers.json`，不在仓库；API 单独计费。

## 本周实验与验收

使用默认正弦信号，输入“二阶 IIR 低通100Hz，再用256点Hann窗FFT看频谱”。检查工具记录、参数预览，应用后比较图表；继续输入“截止改为150Hz”，检查替换已有步骤。保存模型记录、任务 JSON 和实验报告。

每次最多6轮/8次工具调用/90秒。模型处理当前信号，输入和上传仍在网页完成；无逐字流式和长期聊天历史。手动与规则入口可在断网或API失败时继续使用。

已验证：OpenAI协议模拟、本地后端、配置/测试/预览/应用/取消/错误的浏览器流程，以及本周单文件断网运行。**没有使用真实账号请求 OpenAI，真实模型验收需本地补齐。** 详细步骤见根目录 [模型使用与首版验收](../../docs/模型使用与首版验收.md)。

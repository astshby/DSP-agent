双击同目录的 `index.html`，选择 Chrome、Edge 或 Firefox。单个 HTML 文件已经包含所有样式和脚本，可以单独复制到本地或课程提交平台；无需安装软件、服务器和模型密钥。

## 本地验收记录

以下勾选框留给本地运行时填写。自动检查结果单独记录，不代替本人本地验证。

- [ ] **正弦**：fs=8、N=8、f=1、A=1、φ=0、D=0、n₀=0。第 0、2、4、6 项约为 0、1、0、−1，能量为 4，RMS≈0.707107。
- [ ] **相位**：把 φ 改为 90°，n=0 处约为 1；改参数但未点击按钮时，页面说明图形仍为旧结果。
- [ ] **单位脉冲**：点击预设，n=0 为 1，其余为 0；将 k 改为 −3，非零样值移到 −3。
- [ ] **单位阶跃**：点击预设，n<0 为 0，n≥0 为 1。
- [ ] **手动序列**：输入 `[1, 2, 1]`，n₀=−1，采样率留空。范围为 −1…1，能量为 6，不能选时间轴。
- [ ] **时间轴**：给手动序列设置 fs=10，运行后选时间轴，三项对应 −0.1、0、0.1 秒。
- [ ] **错误输入**：`1,,2`、空序列、生成模式 fs=0、N=4097 会提示错误，旧图不会被误标为新结果。
- [ ] **混叠提示**：正弦 fs=1000、f=600，会显示警告；仍允许观察该采样实验。
- [ ] **断网**：断开网络或使用浏览器离线模式后，以上操作仍可执行。
- [ ] **窄屏**：缩窄窗口后，表单与图形按顺序排列，无横向页面溢出。

浏览器中的显示会保留约六位有效数字，浮点结果可能出现非常小的舍入残差；比较时使用数值容差。

## 已知范围

这是有限长度实数序列的时域实验，最多 4096 项。CSV 导入、卷积、频谱、滤波和 Agent 将按后续计划添加。统计值对应本次窗口中的样值，不直接推断无限序列的能量或周期。

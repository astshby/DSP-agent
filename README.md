# DSP 实验台

数字信号处理课程个人项目。先交付可离线运行的信号实验台，再接入 OpenAI 和 DeepSeek。当前版本为 **v0.1 / 第 1 次提交 / 第 5 周**。

## 本地打开：无需安装依赖

1. 在 GitHub 点击 **Code → Download ZIP**，下载后完整解压；也可以 `git clone` 本仓库。
2. 双击 **`self/第五周/index.html`**，用 Chrome、Edge 或 Firefox 打开。
3. 点击“正弦采样”“单位脉冲”“单位阶跃”或“输入一个序列”，修改参数后点击绘图按钮。

这个单文件页面可以单独复制、提交，断网也可运行；不需要 Node.js、Python、服务器或 API Key。不要把 GitHub 的源码预览页面当成正在运行的网页。

根目录 `index.html` 是开发入口，也可直接双击，但它需要保留旁边的 `styles.css` 和 `src/` 目录。

## 当前功能

- 正弦、余弦、脉冲、阶跃发生器，设置频率、幅值、相位与偏置。
- 手动输入离散序列，支持负下标、小数和科学计数法。
- 设置采样率、样本数和首项下标；切换下标轴和时间轴。
- 时域绘图、样值预览、均值、RMS、峰峰值和有限序列能量。
- 输入校验、混叠提示、修改参数后提示重新运行；失败时明确标记保留的旧结果。
- 浏览器与 Node.js 可共用的纯 DSP 模块和统一任务入口。

当前最多 4096 个样值。128 项以内绘制离散竖线与圆点，更多样值用折线连接，数据不抽取。手动序列可以不填采样率，此时仅使用下标轴。相位输入单位为度；时间以 `t=n/fs` 计算，负下标可以对应负时间。

**后续功能**：CSV、序列运算、卷积、差分方程、频域分析、z 变换、滤波器设计、规则/模型助手。它们尚未包含在 v0.1 中。模型配置与本地后端也尚未实现。

## 开发与自动验证

页面没有运行时外部依赖。仅在开发/构建时需要 Node.js 20 或更新版本，无需执行 `npm install`。

```bash
npm test
npm run build:offline
```

`npm test` 验证 DSP 数值、下标、边界和任务校验。`build:offline` 将当前根目录页面打包为 `self/第五周/index.html`。准备后续周版本时指定新的目标，避免覆盖已经交付的历史页面，例如：

```bash
node scripts/build-offline.cjs self/第六周/index.html
```

提交前同步更新页面版本和对应周报。若只想运行当前成果，不需要执行这些开发命令。

浏览器自动检查为可选开发工具，需要 Python 与 Playwright：

```bash
python -m pip install playwright
python -m playwright install chromium
python tests/browser_smoke.py
```

也可以用环境变量 `DSP_CHROMIUM_PATH` 指向已安装的 Chromium 可执行文件。脚本会验证源码入口和单文件入口，拦截外网请求，检查表单、数值、异常状态与窄屏布局。它不会调用模型 API。

云端托管浏览器可能禁止 `file://`：脚本仅在收到该明确策略错误时，改用本地 HTTP 检查源码、在断网状态下加载单文件内容，并打印实际入口方式。这种替代验证不能证明本机双击路径已通过，请按第五周清单完成本地检查。

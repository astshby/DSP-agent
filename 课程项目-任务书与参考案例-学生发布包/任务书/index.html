AI+DSP 课程项目
Web 信号分析 Agent

用户提出信号分析需求，Agent 把需求变成 DSP 任务，并在网页分析器中运行、显示和验证结果。网页提供清晰的程序接口，让 Agent 直接提交任务，不必依赖鼠标逐项点击复杂软件。

个人持续项目本地 Web 应用DSP：滤波 / FFT / 特征模型可插拔，不绑定厂商
从前两章开始：可先看离散信号分析 Agent 小样例，它用“需求 → 任务 JSON → 卷积 → 波形”演示最小闭环；后续再按课程进度加入频谱、滤波等功能。

任务说明

开发一个轻量 Web Signal Analyzer，并在它上面实现一个 DSP Agent。网页负责导入或生成信号、显示波形和频谱、运行基础算法；Agent 接收一句用户需求，检查采样信息和可用功能，形成任务配置并调用分析器。模型层采用可插拔设计，可切换不同厂商的模型服务；也保留规则模式，方便离线测试。每位同学都要完成，并按周提交迭代版本；项目过程可结合课程安排纳入课堂表现、课程作业或综合实验评价。

本题不要求重做 MATLAB Signal Analyzer，也不绑定 Codex 或某一家模型。只实现一个小而清楚的分析器子集，并为 Agent 提供稳定的 JSON / JavaScript 调用接口。不同模型都应输出同一种任务格式，最后由确定性规则检查后再执行 DSP。

Agent 怎么工作

用户说需求

“估计这段信号的主频和幅值，再做平滑滤波。”

→
Agent 生成任务

检查采样率、数据长度，组织成 JSON 操作序列。

→
Web 分析器执行

运行 FFT / 滤波，显示波形、频谱和关键数值。

调用接口示意

runAnalysis({"actions":["estimate_frequency","lowpass"],"sampleRate":1000})

接口可实现为页面内 JavaScript 函数，或本机服务的 HTTP API；学生可选一种。

最低完成要求

Web 分析器

  • 能生成测试信号或导入 CSV。
  • 显示时域波形和频域结果。
  • 至少实现一种 DSP 算法：滤波、幅值 / 频率估计或简单特征提取。

Agent

  • 把一条自然语言或表单需求变成结构化任务。
  • 调用网页分析器并显示可解释结果。
  • 遇到缺少采样率、数据不够或不支持的算法时，指出问题，不猜结果。

多模型接入怎么做

统一适配接口

定义统一的模型调用入口，例如“发送用户需求，返回 DSP 任务 JSON”。每家服务的请求格式差异留在各自适配器里，不改变分析器和 DSP 代码。

可以切换与回退

界面或配置中可选择模型后端；模型不可用时能切回规则模式或模拟响应。核心演示至少跑通一种模型，并展示第二种适配器或可替换后端。

统一校验任务

不论模型来自哪家，都必须输出规定字段；先检查数据、采样率、算法白名单和参数范围，再执行任务。

保护密钥

真实 API 密钥放在本机后端或环境变量中，不写进网页源码、提交仓库或展示给用户。

实施四步

准备数据

生成正弦、含噪信号，或导入一段已有数据。

做分析页面

实现波形、频谱和至少一个 DSP 操作。

连接 Agent

将请求转换为任务 JSON，调用分析器接口。

验证边界

演示一个成功任务和一个应当追问 / 拒绝的任务。

可选扩展：连接 Target

先完成本地 Web Agent；之后可让树莓派或 ESP32 把数据传入网页。常规树莓派需外接采集设备；ESP32-S3 可作为低压采样与显示目标，但要实测 ADC 采样能力。电子墨水屏适合显示分析摘要，不适合连续波形刷新。

每周提交与课堂交流

每周三晚上

提交当周最新版，包括可运行页面 / 程序，以及本周完成内容和遇到的问题。

每周四课堂

教师从阶段成果中选取部分项目，请同学介绍实现思路并开展课堂交流。项目持续迭代，不要求第一周就完成全部功能。

提交与验收

可运行：网页能导入 / 生成信号并完成分析。
有 DSP：至少一种算法有测试信号和验证结果。
可调用：Agent 通过结构化接口发起任务，不依赖脆弱的鼠标坐标自动化。
可换模型：模型接入经过适配，切换后仍输出同一任务结构；可用规则模式做离线回退。
懂边界：数据条件不足时能解释原因或请求补充信息。

MATLAB 可作为参考工具：Signal Analyzer 支持通过 signalAnalyzer(sig) 导入并显示信号，也能生成可复用的 MATLAB 分析脚本；本题用它核对算法结果，不要求 Agent 模拟鼠标操作整个 MATLAB 界面。MathWorks Signal Analyzer 文档 · 脚本生成与自动化说明

范围与安全：基础版使用仿真信号或离线文件；如扩展硬件，只接教师确认的安全低压信号。不要把市电直接接到开发板。Web 分析器是教学原型，不宣称等同专业测量仪器。
为什么先做 Web 版和多模型接口？

Agent 通过明确接口调用分析功能；模型厂商可以替换，DSP 任务格式和执行规则保持稳定。MATLAB 继续承担算法参考与交叉验证；后续接入板卡或工业计算机，也不必绑定某个模型或推翻任务格式。

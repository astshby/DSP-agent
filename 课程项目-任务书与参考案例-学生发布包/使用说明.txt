数字信号处理课程项目｜学生发布包

文件内容
- 任务书/index.html：课程项目任务说明。
- 参考案例/index.html：第一、二章的离散信号分析 Agent 小样例。

打开方式
1. 解压本 ZIP。
2. 双击打开“任务书/index.html”，建议使用较新的 Chrome、Edge 或 Firefox。
3. 在任务书页面点击“离散信号分析 Agent 小样例”进入案例；也可以直接打开“参考案例/index.html”。

参考案例可离线运行，不需要安装软件、启动服务器或填写大模型 API 密钥。页面中的示例输入为 x[-1…1]=[1,2,1]、h[0…1]=[1,-0.5]，可修改序列后点击“解析任务并运行”。

说明：参考案例使用规则解析模拟 Agent，重点展示“自然语言需求 → 结构化任务 JSON → 卷积计算 → 图形结果”的最小闭环。它是供项目起步参考的教学原型，不要求照搬界面或实现方式。任务书中的后续功能可结合课程进度逐步完成。
